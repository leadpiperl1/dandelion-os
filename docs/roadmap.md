# Dandelion Roadmap

## Phase 1: Trust
- stabilize the CI matrix
- make gcc and clang checks mandatory
- keep strict verification green
- validate release artifacts

## Phase 2: Clarity
- simplify the architecture
- reduce duplicate or stale artifacts
- document invariants and safety rules

## Phase 3: Governance
- add contributor guidelines
- define AI guardrails
- establish release review process

## Phase 4: Expansion
- extend tools and monitoring
- improve AI safety telemetry
- strengthen reproducibility and onboarding

## Phase 5: Sovereign deployment
- hardened release process
- mission-specific deployment checks
- operational review of AI actions and system state
